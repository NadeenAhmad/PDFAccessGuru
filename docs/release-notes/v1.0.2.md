A small update.

- **The app has its icon.** PDFAccessGuru in the Applications folder (Mac), the Start menu (Windows) and the app menu (Linux) now shows the PDFAccessGuru picture instead of a blank icon. If you installed an earlier version, the icon appears after the update, the next time you open the app.
- **Clicking the icon always opens the app.** If PDFAccessGuru is already running, clicking its icon opens it again in your browser (before, nothing happened). On a Mac the icon no longer stays in the Dock, because the app runs in your browser.
- **Update now** works right after a new version comes out. The PyPI servers can still give out the old version for a few minutes; PDFAccessGuru now checks which version was installed and tries again for a few minutes, instead of saying "Nothing to upgrade". In a terminal, `pdfaccessguru update` says so in plain words.

To update: in the app, click **Update now** when it says that a new version is available. In a terminal: `pdfaccessguru update`.
