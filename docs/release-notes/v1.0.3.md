A small update with newer AI models.

- **A newer online AI.** With an OpenAI or OpenRouter key, PDFAccessGuru now uses GPT-6 Luna, OpenAI's current fast and low-cost model. Before, it used GPT-4.1 mini (OpenAI key) or Gemma 4 26B (OpenRouter key).
- **Gemma 4 on your computer.** If Ollama has Gemma 4, PDFAccessGuru now uses it before Gemma 3. To get it, run `ollama pull gemma4:e4b` (6.6 GB). Gemma 3 still works if you keep it.
- **Faster descriptions on your computer.** The AI on your computer now answers without a long "thinking" step first. With Gemma 4, a picture description takes about 4 seconds instead of about 30.
- **Clearer picture descriptions.** Some AI models write maths notation or formatting marks, for example `$\rightarrow$` instead of an arrow. PDFAccessGuru now turns these into plain text that screen readers read well ("PDF file → Tags → Screen reader"). Amounts such as "$5" stay as they are.
- **Works with more AI models.** If an AI model does not accept one of PDFAccessGuru's settings, PDFAccessGuru now asks again without that setting instead of falling back to simple rules.

To update: in the app, click **Update now** when it says that a new version is available. In a terminal: `pdfaccessguru update`.
