Set up the AI in the app, without editing a settings file. Fixing PDF files works exactly as in 1.1.0.

- **Paste your key in the app.** Under **Choose who writes the descriptions**, paste your key from OpenAI or OpenRouter and select **Save key**. The app shows only the last 4 characters. **Remove key** deletes it again. The key stays in the settings file on your computer, and PDFAccessGuru sends it only to that company.
- **Choose the model.** If you have several models in Ollama, choose one from the list; for an online AI, type the model name (for example `openai/gpt-6-luna` or `google/gemma-4-26b-a4b-it` on OpenRouter). The app remembers your choice.

1.1.1 is the same as 1.1.0.post1; the new number lets apps with 1.1.0 show the update notice.
