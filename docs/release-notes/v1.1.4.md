Clearer updates and a clearer start page. Fixing PDF files works exactly as in 1.1.0.

- **You see the update happen.** After **Update now**, the page shows the steps (closing, downloading and installing, opening), the time so far and about how long is left. The new version then opens in the same tab and says "PDFAccessGuru was updated to version …". If the update does not work, the page says so and shows the line to paste into Terminal or PowerShell.
- **Update notice right away.** The app asks for a new version every time it opens (in the background, without waiting), instead of once a day. The terminal commands still ask at most once a day.
- **Reopens reliably.** After an update, the app starts itself by its full path, also when it was opened from the Finder or the Start menu.
- **Clearer wording.** Section 2 is now called "Choose who writes the descriptions, such as alt text for images", and the online AI asks for your **API key**.
- **Fewer options when they do not apply.** "How detailed" is hidden when you choose No AI: simple rules always write the same text.
- **Guided tour.** The colour example shows real colours (grey, orange, blue) before and after the contrast fix. The examples are built into the app, so they show even without Ollama or an API key.
