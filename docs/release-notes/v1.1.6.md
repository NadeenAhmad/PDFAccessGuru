A clearer start page on first use and a few more problems fixed. Otherwise, fixing PDF files works as in 1.1.0.

- **The start button works right after the download.** After **Download them now**, the start page notices by itself when the helper programs are ready, and **Make the PDF accessible** can be used without reloading the page. If the download does not work, the page says so.
- **The reason is next to the button.** While **Make the PDF accessible** cannot be used yet, a short line right next to it says why, for example that the helper programs must be downloaded first. Screen readers and other assistive technologies read this line together with the button.
- **More problems fixed.** Some files, for example exported from PowerPoint, have an empty language entry on many pieces of text. They now get the language of the text around them, or of the whole document; before, they stayed open in the report. The tool also finds the right part of the page more reliably, so, for example, a picture that was skipped before now gets its description.
