How well is each version tagged?

Each of 4 short documents (3 pages each) was made accessible by several tools. The versions are shown in a random order and don't say which tool made them. For each version you compare the original pages with what a screen reader reads in that version, and score 13 criteria.

How to score
  1. All content tagged and Reading order: answer for each page.
  2. For every other criterion, count the elements on the 3 pages: correct = tagged right; wrong or missing = tagged as the wrong thing, tagged where there is no such element, or not tagged at all. If the pages have no such element, tick None on these pages.
  3. For "levels", "structure" and "descriptions", count only the elements the version tagged, and whether their level, structure or description is right.
  4. Example: the pages have 5 headings; the version tags 4 of them as headings and also tags one long paragraph as a heading → Headings: correct 4, wrong or missing 2. A figure with the description "Picture" → Figure descriptions: wrong 1.
  5. "Tags found automatically" under the screen-reader view only helps you count; it is not the answer.
  6. Judge each version on its own, and don't discuss the documents with the other judge until you are both done.
