Links, titles and language

Three short tasks. In each, several versions of the same document are shown in a random order without saying which tool made them.

  1. Links: a screen reader announces a link with its text and, if there is one, its description. For each version: does what it announces tell you where the link goes? If a version does not make it a link at all, answer no.
  2. Titles and language: does the title describe the document? Is the document's language right?
  3. Passages in another language: the tool marked these passages as written in another language than the rest of the document. Is the marked language right?
